#PyExcel Convert

![Python](https://img.shields.io/badge/Python-3.8+-blue?logo=python)
![License](https://img.shields.io/badge/License-MIT-green)

PyExcel Converter es una herramienta gráfica para convertir archivos (CSV, Excel, JSON, Parquet, Feather, PDF) entre múltiples formatos, con soporte para procesamiento de datos y generación de informes.


##📌 Características
  - CSV ↔ Excel ↔ PDF
  - JSON ↔ Excel
  - Parquet/Feather → Excel/PDF
  - PDF tables → Excel (text-based PDFs only)

![App Screenshot](./img/cap.png)

##Que use?
   -Python 3.8+
   -Polars: Procesamiento rápido de datos.
   -fpdf2: Generación de PDFs.
   -pdfplumber: Extracción de tablas desde PDFs.
   -Tkinter: Interfaz gráfica.


## 📦 Instalacion
git clone https://github.com/JahirWH/PyExcelConvert.git
cd PyExcel-Converter

##Intala las dependencias con:
pip install -r requirements.txt


## Usar 
Linux- /bin/python3 ./PyExcel.py
windows - acede a la carpeta y solo ejecuta PyExcel.py
